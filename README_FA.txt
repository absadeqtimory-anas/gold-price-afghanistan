اپلیکیشن قیمت طلای افغانستان
نسخه 1.0 - پروژه اندروید

امکانات:
- ورود دستی قیمت انس جهانی و نرخ دالر به افغانی
- دریافت خودکار قیمت XAU از api.gold-api.com
- دریافت نرخ AFN از open.er-api.com
- محاسبه هر گرم عیارهای ۲۴، ۲۲، ۲۱، ۱۸ و ۱۴
- امکان افزودن درصد اجرت/سود به محاسبه
- ذخیره آخرین نرخ‌های واردشده روی گوشی

ساخت APK:
1) Android Studio را نصب کنید.
2) گزینه Open را بزنید و پوشه GoldPriceAfghanistan را انتخاب کنید.
3) صبر کنید Gradle Sync کامل شود.
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
5) فایل APK در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

یادداشت:
- این بسته سورس پروژه Android Studio است، نه APK آماده نصب.
- برای نرخ خودکار اتصال اینترنت لازم است.
- نرخ‌های سرویس‌های بیرونی ممکن است با تأخیر یا قطعی روبه‌رو شوند؛ پیش از معامله واقعی نرخ را با بازار محلی تطبیق دهید.
- قیمت‌ها بر مبنای انس تروا 31.1035 گرم محاسبه می‌شوند.
